# 고려 웹툰 · 요약 근거 기록

고려 웹툰(`media/goryeo-comic.html`)과 고려 강의 요약(`media/lecture-notes.js`의 `goryeo`)을 만든 근거와 한계를 적는다.
웹툰은 `scripts/build_lecture_comics.py`의 `GORYEO`에서 만들어진다(같은 입력이면 같은 결과). 검사는 `scripts/verify-hanq.cjs` 8번 항목이 맡는다.

- 우선순위: 강사의 직접 강조가 1순위, 교재는 사실·용어 확인용 2순위.
- 글은 모두 새로 썼다. 강의 대사·농담·드라마 일화·출제 빈도 주장은 옮기지 않았다.
- 개인 경로는 저장소에 두지 않는다. 근거 생성기는 입력을 밝혀야 돈다: `node scripts/build_lecture_sourcemap.cjs <goryeo_joseon_script_handoff.json 경로>` (또는 `HANQ_LECTURE_HANDOFF`). 경로가 없거나 파일이 없으면 아무것도 쓰지 않고 종료 코드 2로 멈춘다(검사기가 출력 파일이 바이트 그대로인지 확인).
- 다시 만드는 순서: `python3 scripts/build_lecture_comics.py` → `node scripts/build_lecture_sourcemap.cjs <경로>`. 두 생성기 모두 시간·난수·개인 경로를 쓰지 않는다.

## 2. 장면 구성 (20장면)

한 장면 = 한 핵심 개념. 장면 맨 위에 **왕(대수)·재위**와 **연도·사건 줄**을 두고, 그림 아래에 말풍선 둘(말한 사람 표시), 그 아래 **배경 → 전개 → 결과** 줄, **꼭 기억**(강의 핵심어만 굵게), 접힌 보충 순서로 둔다.
장면 사이 줄은 다음 왕으로 넘어가는 말이다. 왕을 건너뛰면 건너뛴 왕의 이름을 밝히거나 ‘중간 왕 생략’ 표시를 단다. 뒤에 나오는 왕이 바로 다음 왕이라고 쓰지 않는다.
펼치지 않고 읽는 줄거리(연도 줄과 장면 사이 줄)의 연도는 앞으로만 간다. 그보다 뒤의 일은 접힌 보충에 “다음 ○○ 때”처럼 밝혀 둔다.

- 기준 데이터: `media/lecture-flow-goryeo.js`(파일 안 `/*FLOW-JSON*/ … /*END-FLOW-JSON*/` 사이 순수 JSON). 생성기 `scripts/build_lecture_comics.py`와 앱(`index.html`의 학습 화면 흐름 바로 가기)이 같은 데이터를 읽는다. 장면 키 S01–S20은 위 표의 장면 01–20과 같고, 장면 순서·id·제목·그림·별칭 앵커는 바꾸지 않았다.

## 3. 연도 · 인과 표현

### 연도의 근거와 한계
- 강의 스크립트에는 연도가 거의 없다. 스크립트가 직접 받치는 것은 사건 사이 간격뿐이다: 이자겸의 난 9년 뒤 묘청의 난(564행), 무신 집권 약 100년(577행), 의천 뒤 약 100년 지눌(691–692행), 공민왕 죽고 18년 뒤 고려 멸망(626행).
- 교재 표 15의 시기 구분(초기 918~1018, 문벌귀족 1018~1170, 무신집권기 1170~1270, 원 간섭기 1270~1351, 말기 1351~1392)은 장면의 연도와 맞는다.
- 원 간섭기는 교재대로 1270–1351로 표시한다. 장면 12는 “1270 개경 환도 뒤 24대 원종 때부터 간섭이 시작되었다”와 “25대 충렬왕(1274 즉위) 때부터 깊어졌다”를 나눠 적는다. 1274는 충렬왕의 즉위 연도이지 간섭이 시작된 해가 아니다.
- 그 밖의 연도와 재위(936, 956, 958, 976, 983, 992, 993, 1010, 1018–1019, 1104, 1107, 1109, 1126, 1135, 1145, 1196, 1231, 1232, 1253, 1273, 1274, 1356, 1366, 1374, 1376, 1377, 1380, 1388, 1389, 1391과 각 왕의 재위)는 표준 고려 연표를 따랐다. 이번 작업에서 공식 출처와 하나하나 대조하지 않았다. 배포 전 한국민족문화대백과사전 등으로 확인할 것을 권한다.
- 왕 대수는 고려 34왕 표준 순서(태조 … 공양왕)를 따르고, 검사기가 화면과 요약의 “N대 ○○” 표기를 이 순서와 맞춰 본다.

### 인과로 읽히지 않게 고친 곳
- ‘결과’에는 앞 단계에서 이어진 일만 둔다. 같은 시기의 다른 사실은 ‘함께’ · ‘같은 때’ · ‘농업’ 꼬리표로 따로 둔다: 광종의 광덕·준풍 연호, 성종의 흑창 → 의창, 태조의 정계·계백료서·훈요 10조, 몽골 침입 때 대장경·황룡사 9층 목탑 소실과 팔만대장경, 고려 농업의 깊이갈이.
- 삼별초 진압과 원 간섭은 “이 무렵부터”로 시간 관계만 적었다. 원 간섭의 원인이 삼별초 진압이라고 쓰지 않는다.
- 공민왕은 “홍건적·왜구 침입이 이어지던 1374, 공민왕이 살해되면서”로 적어, 침입이 피살의 원인이라고 쓰지 않는다.
- 박위의 쓰시마 정벌(1389)은 위화도 회군(1388)보다 뒤이므로 장면 14 본문에서 빼고 “다음 창왕 때”로 접어 두었다.
- 요약 떠올리기는 “이자겸의 난(1126) 다음에 학습 흐름에서 다루는 사건”으로 묻고, 답에 “1126 → 1135, 9년 뒤”를 적는다. 그사이 다른 일이 없었다는 뜻이 아니다.

### 정정 반영(강의 분석의 정정 id)

- 문항 대조는 글자 대조라서, 같은 뜻을 다른 말로 쓴 경우는 놓칠 수 있다. 기출 5문항은 표본일 뿐이다.

원본 저장소에서 생성기 재실행 결과가 같고, 조선 세 HTML·개항기·독도간도 HTML이 이전 커밋과 바이트 단위로 같은 것을 확인했다. 전체 검사 6,222개와 문제 이동 42개가 통과했다. 전용 브라우저에서 320·375·1280px의 20컷(60회), 다섯 흐름 이동(15회), 옛 요약 주소·초점·단일 바깥 스크롤을 확인했다. 지연 로딩 그림의 공간을 실제 비율로 미리 확보하는 수정 후, 최초 iframe에서도 모든 그림 칸의 높이가 양수이고 흐름 이동이 목표 위치에 도착했다. 위 작성자 시점의 생성·화면 확인 대기는 해소됐다. 역사 날짜의 전수 공식 사료 대조나 오디오 재청취를 했다는 뜻은 아니다.
