# 홍문관 시대별 개인 기출

## 등록과 검수
- 목차: 선사 / 삼국 / 남북국 / 고려 / 조선 / 개화기 / 일제강점기 / 대한민국.
- 사용자가 제공한 원본 사진과 정답만 기존 수동등록 절차로 등록한다. 문항, 정답, 풀이 이력을 생성하거나 추정하지 않는다.
- 정답·문항 번호·원본 이미지와 각 보기의 대상을 대조한다. 해설은 각 보기가 어떤 사건·인물·제도인지 명확하게, 보기당 한 문장(화면 기준 한 줄 분량)을 원칙으로 검수한다. 자료가 없으면 '검수된 해설 준비 중'으로 표시한다.
- 기존 ID·내용 버전·소유자·분류와 기록은 보존한다. '고대사'처럼 시대가 모호한 기존 자료는 임의로 선사/삼국/남북국 중 하나에 넣지 않고 확인 대상 수만 알린다.
- 과장 회차별 CBT와 다른 GET /api/v1/hongmungwan 계약을 쓴다. 등록한 시대별 개인 기출만 포함한다.

## 화면과 기록
- 시대 → 개별 문항 선택 → 원문과 보기 → 서버 채점. 각 문항 최근 세 번의 정답/오답만 세 칸으로 표시한다.
- 오답/별표 복습은 reviewOnly=true: 일반 최근 세 번 기록 및 XP에 영향을 주지 않는다.
- 문항/해설 PDF는 해당 시대의 오답/별표 합집합을 중복 없이 읽어 생성한다. PDF 생성은 GET만 수행하며 서버 기록을 수정하지 않는다.
- 데이터 없는 시대는 '현재 준비중입니다.'로 표시한다. API 실패를 빈 문제나 0문제로 가장하지 않는다.
- resetAt와 계정 epoch를 확인해 초기화나 계정 변경 이전 쓰기/다운로드가 뒤늦게 완료되지 않게 한다.

## 확인
- scripts/test-hongmungwan.cjs: 시대 순서, 실제 빈 상태, 최근3회, 복습 비기록, 초기화 토큰, 계정 변경, 중복 자료 차단.
- scripts/test-cbt-wrong-notebook.cjs 및 test-cbt-wrong-pdf.cjs: 과장 독립 기능 회귀.
- 운영 인증계정과 배포 API를 이용한 종단 확인은 배포 후 별도 수행하며, 합성 DOM 테스트를 실사용 검증으로 보고하지 않는다.
