## 쓰는 원칙
- 용어 이름과 짝(왕·인물·책·장소)만 교재에서 가져왔고 설명 문장은 모두 새로 썼다. 판독자의 요약 문장·초안 문장을 옮기지 않았다.
- **굵게 표시**: 교재 본문에서 실제 굵은 글꼴로 확인된 용어(799회 중 해당 시대 묶음의 용어)만. 증거가 비어 있는 46회(예: 훈민정음, 연분 9등법, 이순신, 범금 8조)는 문맥 용어로 보통 글씨.
- **재위한 군주의 이름**은 교재에서 굵어도 제목·표 구분일 수 있어 굵게 하지 않고, 행 앞에 ‘찾기 단서’로 붙였다(예: `세조 · 직전법`). 대상: 고려·조선 왕(묘호), ‘○○왕’, 선덕여왕·진성여왕, 건국 군주(단군왕검·위만·대조영·견훤·궁예·이성계), 뒤에 왕이 된 김춘추, 국외 황제 한 무제. 그 밖의 인물·제도·사건 이름만 굵게 표시한다.
- 굵게 = 교재의 강조이지 출제 빈도 순위가 아니다(화면 안내 문구에 명시). 순위·빈도는 만들지 않았다.
- 원인→결과 화살표(→)는 교재·기존 노트가 그 관계를 보여 줄 때만 썼다.
- 용어 풀이: 기존 공용 사전(`glossary-data.js`, 공식 출처 검증 78개)을 그대로 쓴다. 핵심 개념 행의 용어가 사전에 있으면 그 행 안에서 ‘용어 풀이’를 펼치게 하고, 같은 화면에서 같은 용어는 한 번만 보인다. 행의 짧은 뜻은 교재 맥락을 바탕으로 새로 쓴 설명이며, 공식 사전 검증을 거친 것처럼 표시하지 않는다.

### 조선 범위의 시간 순서
- 전기·양난: 건국과 태종 → 세종 → 단종·세조·성종 → 사화 4개 → 중종·조광조 → 선조·붕당의 시작 → 전쟁과 반정(연도·왕·계기) → 임진왜란 → 광해군 → 인조 → 병자호란 → (조선 전 시기) 중앙 기구 · 향촌 → (태조~명종) 토지 제도 → 전기 왕들의 문화 사업.
- 후기: 효종·현종·숙종 → 영조·정조 → 세도정치기 → 세금 3종(조선 전 시기 비교) → 조선 후기 사회(경제·신분) → 기록물(조선 전 시기) → 실학 → 역사·지리 → 후기 왕과 예술.
- 기존 흐름 노트(`study-notes.js`)도 같은 순서로 맞췄다: 선조 붕당·기축옥사·임진왜란·광해군·대동법·인조반정과 두 호란을 전기 흐름으로 옮기고, 후기 흐름은 효종의 북벌부터 시작한다. 원래 요약 카드·문제 풀은 그대로다.

## 사화(조선 전기) — 사용자 학습 요청 반영
- 네 사화를 한 행에 `연도 · 왕 · 계기`로 묶었다: 무오 1498·연산군·김종직의 조의제문 문제 / 갑자 1504·연산군·폐비 윤씨 사건 / 기묘 1519·중종·조광조 개혁에 대한 훈구 반발 / 을사 1545·명종·외척 윤임·윤원형 세력 대립.
  - 근거: 사화 이름·왕·계기는 교재 PDF 59·61(매핑 joseon-early-07~09). 연도는 사용자가 요청한 표준 연도이며 교재 글꼴 증거가 아니다.
- 떠올리기의 ‘무갑기을 → 연연중명’은 사화 순서와 그때 왕의 짝일 뿐임을 답에 명시하고, 실제 왕위 계승은 `중종 → 인종 → 명종`으로 인종을 넣어 적었다. 화면 어디에도 `중종 → 명종`처럼 인종을 빼고 이어 쓰지 않는다(검증 스크립트가 확인).

## 한계
- 매핑은 “주요 강조 개념을 학습용으로 묶은 선별”이며 모든 굵은 글자·이미지 속 글자의 완전한 전사가 아니다. 이미지로만 있는 도표(PDF 63 등)의 글자는 판독자의 시각 확인에 기댄다.
- 행의 짧은 설명은 교재 맥락과 기존 노트에 기댄 새 서술이며, 각 문장을 공식 사전으로 따로 검증하지는 않았다(공식 검증은 기존 용어 사전 78개에 한함).
