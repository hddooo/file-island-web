공개 데이터: media/history81-term-data.js. 정의와 근거 URL은 해당 데이터에 함께 보존한다. 조율자가 2026-11-05 전달한 검증 목록(기존 docs/glossary-verification.md 및 한국민족문화대백과사전·우리역사넷 확인)에 한정한다. 새로운 역사 설명이나 private 원문은 추가하지 않았다. 44개 시대별 표현은 41개 정의 ID를 사용하며 각 설명은 Unicode 문자 150자 이하다.

PDF source revision: d54c1aa5d5816eeb73a2e82da0ec699555c2cbf1e7cb717a3b84420ed18296de. 원본 MD는 고려245d166b2a25, 조선8d0944e32d86에 고정한다. 다른 판본에는 동작하지 않는다.

실제 chapter/{goryeo,joseon}/webtoon 및 mock의 전용 reader에 연결한다. semantic reader와 source-quiz는 연결하지 않는다. inline parser가 만든 strong/u/허용 색 span만 대상으로 연속 강조 형제를 공백 정규화한 전체 표현과 비교한다. 인접 스타일 조각은 원래 노드를 그대로 묶는다. 비강조·생성 라벨·상호작용 요소는 제외한다. 모르는 표현과 부분 문자열은 설명하지 않는다. 승정원일기·기묘사화는 조선 확장에서 전체 표현으로 등록하며 내부 단어를 따로 연결하지 않는다. 강조와 일반 글자가 이어진 미완성 단어는 제외하고 명확한 분리 조사만 허용한다. 금오는 같은 소속 문단/셀에 의금부·조옥 근거가 있을 때만 연결한다. 삼사는 시대별 정의가 다르다.

실제 원본 7주제×개념/시험 14뷰에서 고려14/14, 조선30/30 표현이 최소 한 번 연결되었다. 표시 위치 합계는 고려26·조선56이며 같은 용어의 반복 등장을 포함한다. 전체193/295 후보나 모든 역사 용어가 구현된 의미는 아니다.

팝업은 plain text와 role=tooltip이며 원본 노드의 글자·색·굵기·밑줄을 유지한다. hover/focus 및 Enter/Space/click/touch, Escape·바깥·scroll 닫기, reader render/stop 정리를 지원한다. 개인 데이터·API·저장 방식은 바꾸지 않는다.

## 고려 추가 범위 (0.3.25-beta)

조율자가 대화로 직접 전달한 고려 142표현을 추가했다. 기존 44표현은 그대로이며 총186 literal 표현, 공백 정규화184키, 정의165개다. Library 파일 전달은 Python 부재로 실행되지 않았고 원래 ZIP/JSON hash 검증을 했다고 주장하지 않는다. 대화 전달본의 문구와 URL을 보존한다. 조선 추가210개는 포함하지 않는다.

실제 7주제×개념/시험에서 고려156개 중139 literal 표현(137 정규화키,129정의)이 201위치에 연결된다. 이 중 신규는125표현이며 기존14표현도 유지된다. 조선30표현/28정의/56위치는 유지된다. 별칭·공백 변형과 반복 위치는 별개다. 모든 후보가 역사 용어이거나 모든 강조에 설명이 붙는 것은 아니다.

미연결17표현: 흥화진, 별무반을 창설, 이 색, 정몽주, 정도전, 홍산대첩, 황산대첩, 홍건적 침입, 왜구 침입, 위화도에서 회군, 개경(개성), 어사대, (전시과), 교장, 백련 결사, 최충 문헌공도(9재 학당), 회계를 담당. 원본 그림/접힌 설명 등에만 있거나 완전한 강조 범위가 아닌 경우를 자동 확장하지 않는다. 교장은 긴 서명의 일부이므로 부분 매칭하지 않는다. 상세 원문 문맥 기록은 비공개 로컬에만 보존한다.

과전은 PDF48/54의 경기 토지 문맥에서만, 회계는 삼사, 전지·시지는 전시과, 제위보는 구제, 강조는 정변, 병마사는 양계, 교장은 경전 문맥에서만 허용한다. 3경은 이번 정의에 등록하지 않았다. 본문이나 강조를 삭제하지 않고 기존 완전 일치 원칙을 유지한다.
