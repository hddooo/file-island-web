웹툰 `media/gojoseon-comic.html`과 장면 지도 `docs/gojoseon-comic-map.json`은 `scripts/build_gojoseon_comic.py`가 만든다(같은 입력이면 같은 결과, 시간·난수·개인 경로 없음). `scripts/build_comics.py`는 이 시대를 건너뛴다.

## 2. 두 흐름

| 흐름 | 컷 | 강의 행 | 교재 |

- ① 고조선은 교재 표 2와 순서 문제(추출본 98–100 · 121–122 · 251–253)의 순서를 따른다: 단군왕검 건국 → 연 장수 진개의 공격 → 위만이 준왕을 몰아냄 → 진번·임둔 복속 → 우거왕 때 한 무제 공격·왕검성 함락(멸망).
- 연나라 장수 진개의 공격(강의 52–53행 · 교재 추출본 104)과 한 무제의 공격(강의 56–57행 · 교재 추출본 109)은 다른 나라 · 다른 때의 공격이다. `scene-2`의 ‘구분’ 줄과 카드의 ‘헷갈리지 않기’에서 나눈다.
- ② 여러 나라는 차례로 이어진 나라가 아니다. 강의의 “부여 밑에 … 고구려”, “고구려 밑에는 옥저”(66 · 72 · 79 · 82행)는 지도에서 남쪽이라는 뜻이다. 그래서 북쪽 부여부터 남쪽 삼한까지 지역 순서로 놓고, 나라 사이를 화살표로 잇지 않는다. 흐름 머리 · 안내 · 잇는 줄에 “차례로 이어진 나라가 아니라 나란히 있던 나라”라고 밝힌다.
- 고조선 다음에 여러 나라를 보는 순서는 강의 59행(“고조선이 망하고 한반도 지역에는 여러 나라들이 생겨나요”)의 정리를 따른다. 다만 화면에는 “고조선에 이어 여러 나라를 본다”라고만 적어, 모든 나라가 고조선 멸망 뒤에야 생겼다는 시간 관계로 읽히지 않게 했다(강의·교재에 나라별 성립 시기가 없어 새로 적지 않음).
- 인과 화살표는 고조선 안에서만 쓴다(교재의 순서). 여러 나라는 정치 · 제천 행사 · 혼인과 사회 · 특산물로 비교만 한다.

## 4. 그림

- 기존 그림 `gojoseon-panels/01–08.webp`(모두 508×380)만 쓴다. 바이트·크기를 바꾸지 않고, 예전 공용 스타일(`.art img{aspect-ratio:1.33;object-fit:cover}` — 508×380은 약 1.34라 거의 맞지만 cover로 잘릴 수 있음)과 확대(`transform:scale(1.40)`)를 쓰지 않아 그림 전체가 원래 비율로 보인다.
- 처음 작성 때는 선사시대 그림과 같은 539×358로 적었지만, 생성기의 크기 확인이 01.webp에서 멈췄고 조정자가 sips로 8장 모두 508×380임을 확인해 고쳤다. 크기 확인은 끄지 않았다.
- 그림 칸(`.gj-art`)은 `style="--gj-ar:508 / 380"`로 실제 비율만큼 먼저 자리를 잡는다. 늦게 불러오는 그림(처음 두 컷만 eager)이 오기 전에도 칸 높이가 0이 되지 않아, 앱의 흐름 바로 가기 뒤 위치가 밀리지 않는다(고려 웹툰에서 고친 문제와 같은 방식).
- 예전에 앞 장면 그림을 확대해 쓰던 덧붙인 장면 4개는 같은 그림 전체를 다시 쓰고, 그림 아래에 “같은 그림 전체를 확대하지 않고 다시 썼어요”라고 밝힌다: `gojoseon-law` ← 01, `wiman-trade` ← 03, `eupgun-samno` ← 06, `samhan-rites` ← 08.

## 6. 받아쓰기 정정 기록

스크립트는 음성 받아쓰기라 이름이 깨져 있다. 화면·데이터에는 교재(PDF 8–15쪽)와 노트 카드의 바른 표기만 쓴다(검사기가 아래 깨진 표기가 화면·흐름 데이터에 없는지 확인한다).

- 고조선: 위이라는 사람 → 위만(49행), 고조선는 → 고조선은(52행), 진계 → 진개(53행), 범근 8조 → 범금 8조(99행), 중개 무역 → 중계 무역(56행), 한 무죄 → 한 무제(56행)
- 부여: 연고 → 영고(61행), 왕건 → 왕권(63행), 일책 12위법 → 1책 12법(64–65행), 소발급으로 기을 → 소의 굽으로 길흉을(65행), 우제 전법 → 우제점법(65행)
- 고구려: 사출가 → 사출도(67행), 개루부 · 손우부 → 계루부 · 소노부(67행), 서을 · 서혹 → 서옥 · 서옥제(70–71행)
- 옥저: 민면느리 · 민면을리제 → 민며느리제(72 · 78행), 옥전 · 옥조 → 옥저(74–78행), 골제 → 골장제(74 · 78행), 과 → 곽(75행), 동의 안 → 동해안(76행)

- 삼한: 변화 → 변한(82행), 사한 → 삼한(82 · 85 · 86행), 신지읍자 → 신지·읍차(83행), 변농사 → 벼농사(86행), 변환 → 변한(87행), 낭랑 → 낙랑(87행)

## 7. 넣지 않은 것

- 위만 조선의 기간(강의 50행 “약 86년”)과 고구려가 옥저를 자주 침략했다는 말(77행)은 교재 표 2·3과 노트 카드에 없고, 나라를 가르는 단서도 아니라 넣지 않았다.
- 변한의 교역 상대는 강의(87행)와 교재(추출본 177 · 217)가 낙랑만 적어, 다른 교역 상대는 넣지 않았다.
