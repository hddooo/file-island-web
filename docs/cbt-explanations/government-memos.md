# 복습 보기의 대한민국 정부 메모

## 범위와 안전 경계

70–80회 보기 136개에 **사건 · 정부(시기) · 연도·보조 단서** 순서의 표시 메모를 지정한다. 원본 해설·공식 정답·문항 버전은 변경하지 않는다. `cbt-round-materials.js`의 `choiceGovernmentMemos`는 문항 버전과 보기 ID에 고정되어 있고, 정식 explanation resolver가 문항·보기·정답 정체성을 확인한 경우에만 적용된다.

런타임에 연도를 대통령 재임 기간에 대입하거나 문장 속 이름으로 정부를 추측하지 않는다. 기존의 `연도 정부` 헤더 중 주체가 명시된 21개도 정적으로 검토하여 순서만 바꿨다. 이미 정부가 앞에 있는 기존 메모는 그대로 둔다. 외국의 발표, 시민 운동, 사회·문화 현상은 정부의 행위로 오인하지 않게 `정부 시기`로 표현한다. 특히 반민특위는 제헌 국회의 활동이고 애치슨 라인은 미국 발표임을 보조 단서에 남긴다.

80회에는 문장형 31개를 명시적 사건 메모로 표시한다. 이전의 왕·종교 연관어 28개는 유지하며, 나머지 191개 문장형 설명은 변경하지 않는다.

## 경계 사례

- 1948년 5·10 총선거·남북 협상은 이승만 **정부 수립 전**이다. 해당 보기들은 정부 메모를 만들지 않는다.
- 1960년 4·19, 허정 과도 정부, 장면 내각은 같은 연도라도 다르다. 4·19 시위는 이승만 정부 시기로 명시하며, 과도 정부·장면 내각 출범과 개헌·총선 보기에는 추정 메모를 붙이지 않는다.
- 1961년 중앙정보부·국가재건최고회의·경제기획원은 `박정희 군정기`로 구분한다. 1962–1966년 계획 같은 복합 기간은 기존 설명을 유지한다.
- 1980년 5·18과 5월 국보위 설치는 `최규하 정부 시기·신군부`, 삼청교육은 `최규하→전두환 정부 시기·신군부`다. 12월 컬러 방송 시작은 전두환 정부 시기다. 이를 전부 1980년 전두환 정부로 뭉뚱그리지 않는다.
- 금 모으기 운동(1998년 초), 제4차 경제개발계획(1977–1981), 다문화가족지원법(2008) 등의 정권 교체 경계는 자동 분류하지 않는다.
- 복수 시대를 비교하는 오답 보기나 잘못된 연결을 논박하는 문장은 그대로 둔다.
