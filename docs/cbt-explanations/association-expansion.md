# 연관 암기어 확장 검수

기준: `4a02368` 로컬 트리(통합 담당 원격 `519afbbf0fce32931b25fbe8ee7d0c6f8f4db521`). 학습 범위 전체 완료가 아니라 **추가 44개 그룹의 점진적 확장**이다.

## 실제 데이터 적용량

70–80회 550문제·2,750보기에 실제 `HanqCbtExplanations.resolve(q, 'final')`과 `choiceNotes`를 적용했다. 연관어 붙이기만 끈 같은 렌더러 결과와 비교하여 단순 정부·연도 재정렬이 아닌 **추가 암기어가 실제로 붙은 보기**를 셌다.

- 주체 그룹: **33 → 77** (+44).
- 연관어 표시 보기: **234 → 566 / 2,750** (+332).
- 새롭게 표시된 332개: 정답 보기 76개·오답 보기 256개.
- 확장 후 전체 표시 566개: 정답 보기 125개·오답 보기 441개.
- 80회 정부 메모 31개 중 단일 정부가 명확한 항목에만 연관어 추가. 기존 왕·종교 메모 유지.
- 나머지 보기는 근거 없는 연관어를 만들어 넣지 않았다.

신규 적용 회차별: 70회 26, 71회 6, 72회 26, 73회 20, 74회 51, 75회 34, 76회 34, 77회 39, 78회 43, 79회 25, 80회 28.

## 출처와 범위

현재 저장소의 `media/era-full-summary-data.js` 및 `media/textbook-notes.js`를 직접 읽고 주체와 연관어의 연결을 검수했다.

- prehistory·gojoseon: 구석기·신석기·청동기·철기, 부여·옥저·동예·삼한·고조선.
- nambuk·goryeo: 원효·의상·설총·장보고, 지눌·의천·최충헌. `textbook-notes.js`의 불교 표에서 지눌의 수선사 결사·정혜쌍수·돈오점수, 의천의 천태종·교관겸수·교장을 구분했다.
- joseon-early·joseon-late: 선조·광해군·인조·효종·현종·조광조·중종. `조선 현종`만 등록하고 고려 현종에는 붙이지 않는다.
- opening: 제1·2차 갑오개혁, 광무개혁, 독립협회, 신민회, 을미개혁.
- colonial: 대한민국 임시 정부, 의열단, 한국광복군, 조선의용대, 신간회, 한국독립군, 조선혁명군. 지청천·양세봉을 단체명에 이미 포함한 별칭에서는 인물명 중복을 제외한다.
- modern: 이승만·박정희·전두환·노태우·김영삼·김대중·노무현·문재인 정부. 해당 정부별 표의 정책·사회 변화·남북관계 단서를 연결했다. 새로운 이명박 정부 묶음은 이번에 추가하지 않았다.

## 표시·안전 규칙

기존 `단서 · 정부(시기) · 날짜` 순서를 보존하고 그 **뒤**에 연관어를 추가한다. 주체가 정확한 단일 정부 이름일 때만 연결하며 `최규하→전두환`, `최규하 정부 시기·신군부`, `군정기`, 날짜만 있는 설명에는 일반 정부 묶음을 붙이지 않는다. 정부 시기라는 표현을 지우거나 외국·민간 활동을 대통령의 행위로 바꾸지 않는다.

보기의 원래 단서·주체·날짜를 공백 무시로 대조하여 이미 나온 연관어를 제외한다. 주체 그룹 선택에는 부분 문자열·연도 추론을 사용하지 않는다. 정답·오답 모두 같은 표시 규칙이고, 공식 정답·문항·서버 기록은 변경하지 않는다.
