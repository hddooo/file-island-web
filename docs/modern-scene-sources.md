## 4. 그림

- 그림판은 12칸이고 행 높이(359 · 386 · 380 · 394)와 열 너비(336 · 340 · 336)가 서로 다르다. 조정자가 읽기 전용으로 흰 줄(가로 359–363 · 750–755 · 1136–1141, 세로 336–341 · 682–687)을 재어 칸 사각형을 정했다. 예전처럼 균등한 3열×4행 배경으로 늘이거나 확대하면 이웃 칸이 섞이고 비율이 달라진다.
- 컷마다 칸 하나를 SVG `viewBox`(x, y, w, h)로 통째로 보여 준다(개화기·일제 강점기 웹툰과 같은 방식). `width`·`height`가 칸 크기라 그림이 늦게 그려져도 칸 높이가 미리 잡힌다. 확대·잘라 내기·늘이기 없음, 그림 파일 편집 없음.
- 원래 장면 12개는 예전 배경 위치(3열×4행)와 같은 칸 1–12를 하나씩 쓴다. 예전에 칸 일부를 확대해 쓰던 덧붙인 장면 6개는 같은 칸 전체를 다시 쓰고, 그림 아래에 “같은 칸 전체를 확대하지 않고 다시 썼어요”라고 밝힌다: `constituent-tasks` ← p03, `rhee-amendments` ← p03, `yushin-end` ← p06, `chun-government` ← p07, `ys-government` ← p07, `inter-korean` ← p11.
- 덧붙인 장면의 그림 설명은 칸 전체에 맞게 “○○ 장면과 같은 그림(칸 전체 다시 사용)”으로 바꿨다.

## 6. 받아쓰기 정정 기록

스크립트는 음성 받아쓰기라 이름·숫자가 깨져 있다. 화면·데이터에는 노트 카드와 기존 장면의 바른 표기만 쓴다(검사기가 아래 깨진 표기가 화면·흐름 데이터에 없는지 확인한다).

- 사실(연도) 정정: 한국민주당 창당 1948년 9월 → 1945년 9월(1858행. 강의도 같은 줄에서 “광복이 되자마자 … 바로 생겨났다”고 말하므로 1948은 받아쓰기 오류로 본다). 화면에는 `scene-1`의 접힌 보충에 1945년 9월로만 적는다. 조정자 확인: 국사편찬위원회 한국사데이터베이스 「한국민주당 결당식」은 1945년 9월 16일 기록이며, 매일신보 1945년 9월 17일 기사를 출전으로 제시한다. https://db.history.go.kr/id/dh_001_1945_09_16_0160 (2026-10-07 확인).
