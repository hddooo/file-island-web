본문 연결 범위는 `.textbook-semantic-content .textbook-semantic-line`이다. 강조 span·strong으로 나뉜 용어도 원래의 텍스트·강조 요소·속성을 보존한 채 연결한다. 한 용어의 키보드 진입점은 하나이며 모든 글자 조각을 마우스/터치로 열 수 있다. 입력·버튼·링크·편집 가능한 영역·숨김·빈 응답 예시 표·문항/정답 영역은 제외한다. 미등록 용어나 이미지 안 글자는 추정해서 설명하지 않는다. 렌더러·index·교재 자료·문항·정답·ID·계정 진도·API 계약·배포 설정은 이 변경에서 수정하지 않는다.

팝업은 비모달이며 hover/focus로 표시하고 클릭/탭으로 고정한다. Enter/Space로 내부 조작에 진입하고 출처 링크를 탐색할 수 있다. Escape/닫기는 용어로 초점을 돌려주며, 바깥 탭·초점 이탈·화면 이탈·원래 본문 제거 시 닫힌다. 스크롤 중 보이는 용어를 따라 위치를 다시 계산하고 화면 밖으로 사라지면 닫는다. 팝업 안을 스크롤할 때는 유지한다. 작은 화면에서 글이 잘리지 않도록 가시 viewport와 화면 네 경계를 적용한다.

검수 명령: `node scripts/qa-textbook-keywords.cjs`. 기존 `.test-tools/node_modules`의 Playwright와 `qa-vocabulary-video-bar.cjs`가 사용하는 `playwright` 모듈이 필요하다. 모듈 탐색 경로는 해당 환경의 `NODE_PATH` 또는 로컬 설치를 사용한다. 전체 앱 CSS·라우터와 실제 semantic renderer를 사용하지만 API·본문은 합성 fixture이며 운영 쓰기는 차단한다. Chromium/WebKit × 320×640, 390×844, 1440×900, 844×360에서 키보드·강조 분할·모바일 탭·팝업 경계·읽기/답안 불변·remount/route 정리를 검사한다. macOS WebKit의 링크 탐색에는 OS의 기본 전체 컨트롤 탐색인 Option-Tab을 사용하며 제품이나 OS 설정을 바꾸지 않는다. 결과 JSON·PNG는 작업 공간 `evidence/keywords`에 별도 보관한다. 실제 iPhone/VoiceOver·실제 교재 내용 전수 대조·실제 운영 배포 검증을 뜻하지 않는다.
