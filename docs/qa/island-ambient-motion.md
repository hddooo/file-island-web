# 섬 물·바람 효과 검수

대상: 영어섬 세로/가로 원화, 전체지도. 캐릭터·학습 기록·배경 원본·클릭 영역은 변경하지 않는다.

## 구현

- `island-living-water.js`: 영어섬에도 실제 잎 색상을 고르는 파란 채널을 사용한다. 건물·포털·지붕을 제외한다. 세로/가로 폭포는 조사한 구역 안의 물 색상만 녹색 채널로 등록한다.
- Canvas2D fallback은 수면·폭포·잎을 따로 그린다. 역사섬의 기존 바람 세기와 폭포 없는 경로의 메모리 사용은 유지한다.
- `world-map.js/css`: 원래 지형·클릭 윤곽은 유지하고 작은 효과만 움직인다. 실제 폭포가 있는 네 가로/다섯 세로 위치에 흐름을 추가한다. 가로 문의섬에는 폭포가 없어 효과를 넣지 않는다. 세로 재배치에는 섬 그룹을 그대로 따른다.
- 숨김/화면 밖 정지, 제거 시 정리, 원화 실패 시 효과 숨김과 reduced-motion 정적 보기를 유지한다.

## 수동 회귀 검사

별도 테스트 도구 위치의 `jsdom`, `@napi-rs/canvas`를 `HANQ_JSDOM`, `HANQ_CANVAS`로 지정할 수 있다. 기본은 Node 모듈 검색을 따른다. CI 단계는 추가하지 않는다.

```
node scripts/test-island-map-ambient.cjs
node scripts/test-island-living-water.cjs
```

기본 원화는 저장소 `media/world-art`에서 읽는다. `HANQ_AMBIENT_ROOT`, `HANQ_AMBIENT_ART`, `HANQ_QA_DIR`로 후보 저장소·원화·출력 경로를 지정할 수 있다. 출력은 기본적으로 임시 폴더 `hanq-ambient-qa`에 기록한다.

## 배포 전 실제 실행 범위

- 지도 320×500, 390×780, 700×410, 1440×900 합성 DOM/WAAPI 회귀 통과. 목적지 클릭, 원화 실패·복구, 숨김·화면 밖·재진입·제거, reduced-motion 검증.
- 영어섬 실제 원화의 세로/가로 × 일반/저사양 4조건 Skia Canvas2D 렌더 검증 통과. 시간별 폭포·물·잎 픽셀 변화를 확인하고 선택한 포털·지붕 영역은 고정됨을 검사했다.
- 독립 원화 대조에서 가로 문의섬의 잘못된 폭포 후보를 제거했다. 코드·CSS 구문 검사를 통과했다.

이 검사는 실제 iPhone Safari, 실제 GPU/WebGL, 프레임레이트나 전체 운영 화면 검증이 아니다. 운영 커밋·배포·실제 브라우저 확인은 배포 뒤 별도로 보고한다.
