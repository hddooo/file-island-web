# 일제 강점기 웹툰 · 근거와 구성 기록

웹툰 `media/colonial-comic.html`과 장면 지도 `docs/colonial-comic-map.json`은 `scripts/build_colonial_comic.py`가 만든다(같은 입력이면 같은 결과, 시간·난수·개인 경로 없음). `scripts/build_comics.py`는 이 시대를 건너뛴다.
흐름 머리와 ‘이 부분에서 외울 것’ 카드, 굵게 보일 말(`terms`)은 `media/lecture-flow-colonial.js`의 `/*FLOW-JSON*/ … /*END-FLOW-JSON*/`를 읽는다. 앱(`index.html`)도 같은 데이터로 학습 화면의 네 흐름 바로 가기와 안내를 그린다. 검사는 `scripts/verify-hanq.cjs` 12번 항목과 동작 검사가 맡는다.

## 2. 네 흐름

강의는 일제 강점기를 통치 방식으로 셋으로 나눈다(1609–1611행: 1910년대 · 3·1 운동 뒤 이른바 문화 통치 · 1937 중일 전쟁 뒤 민족 말살 통치). 그 안에서 국내의 사회·경제 운동을 함께 다루고(1612–1747행), 독립운동사는 따로 다룬다(1747–1773행). 문화(1774–1805행)와 인물(1806–1815행)은 마지막에 덧붙인다. 웹툰도 이 순서를 따른다.

- 예전 웹툰은 통치와 독립운동을 섞어 연도 순으로 놓았다. 강의 순서로 다시 놓으면서 장면 18개의 id·제목·꼭 기억·대사는 그대로 두었다. 예전 링크(`#scene-1` … `#language-history`)는 모두 같은 장면으로 간다.
- `language-history`(조선어학회·민족 사학)는 1920년대부터 이어진 주제별 정리지만, 강의가 일제 말 조선어학회 사건(1793–1794행)과 민족 말살 통치를 함께 묶을 수 있게 ③에 두고 제목 줄에 “주제별 · 여러 해에 걸친 정리”라고 밝혔다.

## 4. 그림

- 그림판은 12칸이고 행 높이(370 · 366 · 355 · 421)와 열 너비(338 · 334 · 338)가 서로 다르다. 조정자가 읽기 전용으로 흰 줄(가로 370–377 · 744–751 · 1107–1114, 세로 338–344 · 679–685)을 재어 칸 사각형을 정했다. 예전처럼 균등한 3열×4행 배경으로 늘이거나 확대하면 이웃 칸이 섞이고 비율이 달라진다.
- 컷마다 칸 하나를 SVG `viewBox`(x, y, w, h)로 통째로 보여 준다(개화기 웹툰과 같은 방식). `width`·`height`가 칸 크기라 그림이 늦게 그려져도 칸 높이가 미리 잡힌다. 확대·잘라 내기·늘이기 없음, 그림 파일 편집 없음.
- 원래 장면 12개는 예전 배경 위치(3열×4행)와 같은 칸 1–12를 하나씩 쓴다. 예전에 칸 일부를 확대해 쓰던 덧붙인 장면 6개는 같은 칸 전체를 다시 쓰고, 그림 아래에 “같은 칸 전체를 확대하지 않고 다시 썼어요”라고 밝힌다: `singanhoe` ← p03, `social-movements` ← p02, `language-history` ← p05, `secret-societies` ← p06, `uiyeoldan` ← p09, `manchuria-1930s` ← p07.
- 덧붙인 장면의 그림 설명(aria-label)은 칸 전체에 맞게 “○○ 장면과 같은 그림(칸 전체 다시 사용)”으로 바꿨다. 예전 설명(“등불 아래 모여…”, “폭탄을 손질하는…”)은 확대한 일부를 설명한 것이라 칸 전체와 맞지 않을 수 있다.

## 6. 받아쓰기 정정 기록

스크립트는 음성 받아쓰기라 이름이 깨져 있다. 화면·데이터에는 노트 카드와 기존 장면의 바른 표기만 쓴다(검사기가 아래 깨진 표기가 화면·흐름 데이터에 없는지 확인한다).

- 통치: 강정기 · 강전기 → 강점기, 3일 운동 → 3·1 운동, 환병 · 선변 경찰 → 헌병 경찰, 태양령 → 태형령, 문독 · 문간 총독 → 문관 총독, 동화일보 → 동아일보, 치한 유지법 · 치한 주지법 · 시안 유지법 → 치안유지법, 삼미 증식 계획 → 산미증식계획, 소장농 → 소작농, 소작장위 → 소작쟁의, 조선 물산 공지회 · 조선물상 공지 → 조선물산공진회, 경북궁 → 경복궁, 한국 신민서사 → 황국신민서사, 창시 계명 → 창씨개명, 사상범 예방 구급령 → 사상범 예방 구금령, 금성 → 금속
- 3·1 운동·임시정부: 제압리 → 제암리, 당은식 → 박은식, 지열사 → 지혈사, 독립 공체 · 독립공책 → 독립공채, 교통 국가 → 교통국, 조소왕 · 조소항 → 조소앙, 3균주의 → 삼균주의

- 사실 정정(받아쓰기가 아니라 강의 표현을 그대로 옮기면 틀리는 곳):
  - 3·1 운동: 강의(1634–1635행)는 “고종의 장례일에 맞춰서 … 만세 운동이 시작”이라고 말하지만, 3·1 운동은 고종의 인산일(국장)보다 앞서 시작되었다. 화면·카드는 “고종의 인산일을 앞두고 사람들이 모인 가운데 3·1 운동이 시작되었다”로 적고, 같은 날로 쓰지 않는다. 6·10 만세 운동은 순종의 인산일 당일에 일어난 것이 맞다(1687–1688행). 조정자 확인: 한국학중앙연구원 한국민족문화대백과사전 「3·1운동」은 고종 인산일이 3월 3일로 정해졌고, 운동 날짜는 3월 1일로 바뀌었다고 설명한다. https://encykorea.aks.ac.kr/Article/E0026772 (2026-10-07 확인).
  - 조선어학회 사건: 강의(1793–1794행)는 “강제 해산”이라고 말하지만, 화면·카드는 “탄압을 받아 활동이 중단되었다”로 적어 공식 해산이라고 단정하지 않는다.
  - 북간도 학교: 강의(1807행)가 이상설과 묶는 것은 서전서숙뿐이다. “이상설이 세운 서전서숙이 있었고 명동학교도 있었다”로 나눠 적는다(독도와 간도 웹툰과 같은 표현).
- 확인하지 못한 받아쓰기: 1768행의 “쌍대 전투”와 “영흥 전투”는 바른 이름을 노트·교재에서 찾지 못해 쓰지 않았다.

## 7. 넣지 않은 것

강의 대조 범위(1607–1815행)와 노트 카드·기존 장면에 없는 내용은 넣지 않았다: 민족 대표 33인, 즉결 처분, 병참 기지화, 임시정부 국무총리 이동휘, 형평사의 강상호, 한국독립군의 중국군 연합, 진단학회의 ‘실증’ 성격. 진단학회는 강의 표현대로 “식민 사학에 맞서 결성된 학회”로만 적는다.
