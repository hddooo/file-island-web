## 1. 화면 구성(위에서 아래로)

1. **한눈에(맨 위)**: 1910년대 무단 통치 · 1920년대 이른바 문화 통치 · 1930년대 이후 민족 말살 통치의 세 큰 구간을 먼저 보인다. 각 구간에는 일본의 통치 · 경제 수탈 · 우리의 독립운동을 적는다. 1919·1931·1937년은 큰 구간 안의 전환점이며, 아래 기존 네 세부 시기를 접힌 상세로 유지한다.
   - 기준점: 1910 국권 피탈 → 1919 3·1 운동 → 1931 만주사변 → 1937 중일 전쟁 → 1945 광복.
   - 시기와 범주:

     | 시기 | 범주 |
     | --- | --- |
     | ① 1910–1919 | 무단 통치 |
     | ② 1919–1930 | 이른바 문화 통치 |
     | ③ 1931–1936 침략 확대와 전쟁 준비 | 민족 말살 통치 |
     | ④ 1937–1945 전시 총동원과 황국 신민화 | 민족 말살 통치 |

   - ③과 ④는 같은 ‘민족 말살 통치’ 묶음 안에 둔다.
   - 아래에 짧은 읽기 길잡이를 둔다: 경계의 해는 길잡이일 뿐이다. 동화 정책은 1936년 무렵부터 강해졌고 1937년 중일 전쟁 뒤 전시 동원이 본격화됐다. ‘대륙 병참 기지화’ 방침은 1938년 공식화됐고, 그 앞 1930년대에는 공업화 준비가 이어졌다.
2. **시기별 자세히**(각주 0번 교재 쪽 표기: PDF 106–122쪽 = 책 99–115쪽): 네 시기마다 흐름 줄, 그다음 일본의 통치 → 경제 수탈 → 우리의 독립운동 순서다. ②에는 ‘1919 경계 · 3·1 운동과 대한민국 임시정부’ 칸이 있다.
3. **여러 시기에 걸친 것**: 연대로 가르기, 임시정부의 길(1919–1945), 국외 한인 사회, 민족 문화·종교·언어·역사(대한제국 시기에 시작된 것부터 1945년까지).
4. **헷갈리는 짝(5) · 떠올려 보기(7)**: 원래 흐름 노트·교재의 짝과 문제를 그대로 펼쳐 두고, 필요한 곳에 ‘더 정확히’를 붙인다.
5. **원래 정리 보기(접힘)**: 시기 구분 전 교재 묶음을 예전 화면 그대로 둔다. 그 아래 원래 카드 10장(‘시험 단서 노트 전체 보기’)도 그대로다.
   - 두 접힌 칸 맨 앞에 각각 ‘옛 표현과 함께 확인’ 묶음을 둔다. 접힌 칸만 따로 읽어도 줄인 표현을 바로잡을 수 있도록, 아래 4절의 민립·간도·독사신론·만세보·창씨개명·징용 설명 6개를 보인다.
   - 같은 `notes` 글을 키(`oldFoldNotes`)로 다시 그리므로 위 설명과 내용이 갈라지지 않는다.
   - 일제 강점기에만 붙고, 원래 카드 글과 교재 55행은 그대로다.
6. **참고 자료(각주)**: 번호 목록으로 둔다. 본문에는 `[번호]` 표시만 하고, 주소(#)를 바꾸는 링크는 쓰지 않는다(앱의 주소 이동과 섞이지 않게).

## 2. 원래 자료를 가리키는 배치표

`media/colonial-summary.js`는 문장·용어를 다시 쓰지 않고 가리킨다.

| 표시 | 원래 자료 | 수 |
| --- | --- | --- |
| `card:i:j` | 원래 요약 카드 i의 j번째 문장 | 10장 · 45문장 |
| `tb:g:r` | `HANQ_TEXTBOOK.colonial.core[g].rows[r]`(교재 굵은 글씨·용어 풀이 그대로) | 7묶음 · 55행 |

- 맨 위의 짧은 요약(`brief`)·길잡이·③의 두 설명 줄(`say`)·‘더 정확히’(`notes`)는 새로 쓴 짧은 글이다. 교재 PDF 106–122쪽(책 99–115쪽)과 아래 사료에 근거한다.

## 5. 경계에서 정한 것

- **③ 1931–1936**: 1930년대 초 한중 연합 무장 투쟁(한국독립군·조선혁명군), 한인애국단, 강주룡(1931), 브나로드, 조선 혁명 간부 학교, 남면북양(1932~)·공업화 준비, 농촌 진흥 운동(1932~1940).
- **④ 1937–1945**: 국가 총동원법(1938)·애국반, 황국 신민 서사·조선 사상범 예방 구금령(1941), 창씨개명(1939 법령·1940 시행), 강제 동원, 조선의용대(1938)·한국광복군(1940).
- **남면북양**: 원래 카드 문장(card:2:0)은 남면북양과 국가 총동원법을 한 문장에 담는다. 그래서 ④ 경제 수탈에 ‘남면북양 1932~ · 국가 총동원법 1938’ 표시와 설명을 붙여 두었다. ③에는 남면북양을 짧게 다시 설명한다.
- **원래 카드의 ‘연대 구별’ 문장**은 맨 위에서 빼고 ‘연대로 가르기’ 칸으로 옮겼다.
- **일본군 위안부**는 원래 일제 강점기 자료에 없는 항목이다. 새 항목으로 넣지 않고, 징용 설명 안에서 여자 정신 근로령과 다르다는 구분만 적었다.

## 6. 한계

- 다른 시대 자료의 같은 내용은 이번 범위가 아니라 고치지 않았다(예: 독도와 간도 카드의 ‘청산리 승리 뒤 간도 참변’ 표현).
- 조선 혁명 간부 학교를 ③에 둔 것은 일반적인 시기 지식에 따른 배치다. 교재는 의열단 칸(1920년대 표)에 함께 적는다.
- 화면 배치·휴대폰 줄바꿈은 조정자의 실제 브라우저 검사로 확인해야 한다(작성자는 실행하지 못함).
