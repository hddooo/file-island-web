## 4. 그림

- 기존 그림 `prehistory-panels/01–08.webp`(모두 539×358)만 쓴다. 바이트·크기를 바꾸지 않고, 예전 공용 스타일(`.art img{aspect-ratio:1.33;object-fit:cover}`)과 확대(`transform:scale(1.45)`)를 쓰지 않아 그림 전체가 원래 비율로 보인다.
- 그림 칸(`.p-art`)은 `style="--p-ar:539 / 358"`로 실제 비율만큼 먼저 자리를 잡는다. 늦게 불러오는 그림(처음 두 컷만 eager)이 오기 전에도 칸 높이가 0이 되지 않아, 앱의 흐름 바로 가기 뒤 위치가 밀리지 않는다(고려 웹툰에서 고친 문제와 같은 방식).
- 예전에 앞 장면 그림을 확대해 쓰던 덧붙인 장면 4개는 같은 그림 전체를 다시 쓰고, 그림 아래에 “같은 그림 전체를 확대하지 않고 다시 썼어요”라고 밝힌다: `paleo-sites` ← 02, `neo-village` ← 03, `bronze-village` ← 06, `iron-trade` ← 08. 그림 설명도 그림 전체에 맞게 “앞 장면과 같은 그림 · 그림 전체 다시 사용”으로 바꿨다.

## 6. 받아쓰기 정정 기록

스크립트는 음성 받아쓰기라 이름이 깨져 있다. 화면·데이터에는 교재와 노트 카드의 바른 표기만 쓴다(검사기가 아래 깨진 표기가 화면·흐름 데이터에 없는지 확인한다).

- 구석기: 댄석기 → 뗀석기(21행), 승배 찌르게 → 슴베찌르개(22행), 짚고 → 짓고, 전공훈리 → 전곡리(22행)

- 청동기: 변농사 → 벼농사(34 · 37행), 조피, 수수 → 조·피·수수(34행), 별을 벨 → 벼를 벨(38행), 농경문이 청동기 → 농경문 청동기(38–39행), 방구대 → 반구대(40–41행), 환우 → 환호(40행)
- 철기: 오답원 → 오답, 비파용 동검 → 비파형 동검(43행), 독적인 → 독자적인(43행), 반량점 → 반량전(44행), 세스랑 → 쇠스랑, 굉이 → 괭이(45행)

## 7. 넣지 않은 것

- 강의가 덧붙인 최신 소식(41–42행 “작년 2025년에 세계 문화유산으로도 등재”)은 넣지 않았다. 반구대 바위그림은 유적지 목록(접힌 보충)에만 둔다.
- 유적지 목록은 강의·교재 모두 “몰라도 된다”고 해서 펼친 본문·카드에 올리지 않았다.
- 철기의 정복 활동·여러 나라 성장 같은 내용은 다음 단원(고조선과 여러 나라)의 범위라 넣지 않았다. 교재 표 1의 철기 무덤(독무덤·널무덤)과 오수전은 접힌 보충에만 둔다.

## 8. 검사(`scripts/verify-hanq.cjs` 14번과 동작 검사)

- 12컷의 순서·id·제목·꼭 기억(기준본과 같음), 모든 컷이 펼친 채인지, 예전 확대(transform)·그림 위 말풍선이 남지 않았는지, 진행 막대와 공용 스크립트가 남았는지 본다.
- 그림 01–08이 모두 539×358인지, 컷마다 그림 전체를 쓰고 칸이 그 비율로 자리를 먼저 잡는지(처음 두 컷만 eager), 원래 장면 8개가 그림 01–08을 하나씩 쓰는지, 다시 쓴 4컷에 표시가 있는지 본다.
- 읽는 순서, 말풍선 표시(설명용 인물 · 해설)와 글자 크기, 설명·카드의 굵은 말이 `terms`뿐인지, 강의 강조 줄과 근거 행 기록을 본다.
- 네 흐름 머리 위치, 시대가 바뀌는 잇는 줄 3곳, 카드 4장의 위치·내용·헷갈리는 짝, 생활·도구 단서가 펼치지 않아도 보이는지, 유적지 목록은 접힌 보충에만 있는지, 받아쓰기 오타·최신 소식이 없는지 본다.
- 바로 가기 줄(60px · 홈 버튼 자리 92px · 링크 44px와 초점 테두리 · 앵커 68px · 앱 안에서는 숨김 · 움직임 줄이기), 마지막 빈칸 문제 링크, 노트 5장·빈칸·기출이 기준본 그대로인지, 앱의 탭 셋·네 흐름 바로 가기·초점 이동·높이 맞춤·옛 요약·빈칸·실전 주소, 예전 앵커를 본다.
