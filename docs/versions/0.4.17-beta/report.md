# Part 7 표시 변경 결과

문자 대화·이메일 등 지문 종류를 누르면 같은 제목으로 이동하던 중복 버튼을 제거했다. 실제 문서 제목과 분할·원문·근거 표시 및 읽던 지문/문제 이동은 그대로 유지한다.

출처 행은 예를 들어 `1회_지면모의고사 · 원문 151~152번`으로 표시한다. 여러 구간은 `151~152·155~157번`처럼 압축하며 빈 번호를 포함하지 않는다. 원문 식별자의 번호가 있으면 그 번호를 사용한다. 중복 개수 요약은 제거했지만 실제 오답이 아닌 공통지문 복습 문항의 안내는 유지한다.

합성 검사에서 원문·보기·묶음 채점·재풀이·해석·문항 이동·다른 파트 출처 표기를 확인했다. 사용자 답안·XP·운영 데이터에는 검사 쓰기를 하지 않았다. 로컬 브라우저 실행이 소켓 제한으로 막혀 별도 실제 운영 화면 확인이 필요하다. 이 문서는 배포 성공을 주장하지 않는다.
