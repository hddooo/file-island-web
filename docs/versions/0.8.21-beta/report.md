# 0.8.21-beta 변경과 검증

기존 고려·조선·개화기 전용 학습과 별도로 5시대 학습/시험/빈칸/핵심요약, 인물·지역 읽기를 검증된 81판 API에 연결한다. 원문·그림은 인증 API에서 제공하며 공개 정적 파일에 교재를 포함하지 않는다.

## 보존
구79판을 명시 선택하면 기존 API/진행기록 경로를 유지한다. 시대 전환 시 자동 선택된 판 정보만 해제하며 사용자의 명시 선택은 보존한다. 기존 답안/XP/체크/별표/과장/홍문관 데이터를 수정하지 않는다.

## 검증
실제 index와 원문 fixture 기반 36개 화면 및 lifecycle6항목을 검사했다. 학습7영역×320/390/1440, 5시대 시험/빈칸/요약390px에서 가로넘침·오류·재시도 표시가 없었다. 실제 PNG/JPEG 로드와 대표 화면을 검토했다. 빈칸307개를 확인했다. 기본판139, summary route80, summary41, revisions73, semantic library81, glossary45표현, 기존 용어431형식, 개화기 app21 및 transport 회귀검사 통과.

## 제한
실제 회원 답안/XP를 쓰는 운영 테스트는 하지 않았다. 구판 전환의 클라이언트 API 호출은 확인했으나 이 브라우저 fixture에 구판 manifest가 없어 구판 전체 렌더는 재검사하지 않았다. 서버 격리 통합검사로 구판/사용자 분리를 확인했다.
용어 팝업은 기존 검증된 짧은 정의34개·별칭45개만 재사용한다. 원문 강조 전체 일치에 한정되어 검사한65페이지에서 실제4건만 표시됐다. 전체 용어 보충이나 고려·조선 수준의 용어설명 완성을 의미하지 않는다. 전체137페이지의 사람에 의한 원문대조 완료를 주장하지 않는다.
