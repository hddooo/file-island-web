# 0.8.0-beta 결과

## 구현

기존 Practice의 Part 1 / Part 2 / Part 3·4에서 음원 듣기를 열면 기존 플레이어 아래 재생목록이 나타난다. 회차별 선택, 자동 다음 곡, 속도·반복, 곡별 Practice 진입과 복귀를 지원한다. 원본 목록을 누적 정오답 이력으로 다시 거르지 않는다.

음원 ZIP과 문제지·해설지 PDF는 기존 동작을 유지한다. 음원 미등록 묶음은 제외한 개수를 안내하고, 음원 조회 실패는 기존 재시도 UI를 사용한다. API·DB·정답·개인 풀이 기록 변경은 없다.

## 검사와 배포 상태

합성·회귀 검사와 공개 정적 빌드를 실제 사용자 로그인 검증과 구분한다. Windows 화면 검사와 정확 SHA CI/CD·실제 도메인 대조는 진행 중이며 운영 완료로 표시하지 않는다. 최종 결과는 후속 상태 기록에 남긴다.
