# 0.6.4-beta 진행

- 공통 shell padding·header 음수 margin과 지도 중복 윤곽 정리 완료.
- 원래 하드웨어의 clipping 한 번만 사용해 경로별 radius 차이로 생기는 이중 모서리를 피한다. 읽기 패널에는 새 radius나 overflow 제한을 추가하지 않는다.
- CSS 구문·32 DOM scope 조합·wheel 21·위치/탐색 43 및 header 회귀/대비 검사 통과.
- 격리 Chromium은 실행 전 socket 권한 제한으로 종료되어 모바일/시각 검사를 통과로 기록하지 않는다.
- main의 정확 SHA 빌드·배포 및 운영 확인은 위 사전 검사와 별개이며 해당 배포 실행 결과로 확인한다.
