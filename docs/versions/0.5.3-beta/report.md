# 역사 회사모드 사전검수

## 변경

- shared steps 및 고려/조선 topics/modes를 원본 선택 상태가 보이는 파일 탭으로 표시한다. 숨겨진 구형 toc 및 비활성 원문 메뉴는 노출하지 않는다.
- 모의고사 회차의 독립 시작/다시확인/오답만 스위치를 보존하면서 파일 행으로 표시한다.
- 오답 재풀이와 lazy details summary를 파일 행으로 표시하고, 흰 좌우면·굵은 테두리를 정리한다. 원래 오답 텍스트와 펼침 상태를 유지한다.
- legacy review toc의 data-group을 시대 data-id와 분리해 잘못된0개 헤더를 바로잡는다.
- 고려/조선 카드·문단·표 외부 여백을 적당히 줄인다. 이미지 전용 figure-group wrapper만 그림 없는 텍스트 흐름으로 바꾸며 caption/status를 보존한다. coordinate diagram, source timeline, source crop과 표 내부 너비/스크롤은 변경하지 않는다.
- body직속 이미지 설명도 회사모드 해제/역사 이탈 시 정리한다. 원본 media 노드/src/alt는 보존한다.

## 검수 범위

새 역사 DOM/CSS21개와 기존 메뉴8개·회사모드18개 독립 회귀(합계47개), 버전 빌더가 통과했다. 원본 handler·DOM identity·disabled·switch·lazy details·반복 복귀·숨김 제어·CSS scope를 검사한다. 전체 저장소 검사/실기기 검증으로 표현하지 않는다.

수정 전 실제 운영에서 역사 메인, 시대 선택, 회차10개, 오답76개, 선사 원문, 고려/조선 내부 메뉴를 확인했다. 조선 본문 카드에32px padding/24px margin이 남음을 확인했다.

선사 회사모드 첫 원문 로딩 중 Chrome 오류9가1회 발생했다. 일반모드 동일 원문 로딩, 회사모드 전환 및 회사모드 재접속을 다시 확인했을 때 정상이며 원인은 확정하지 못했다. 추정으로 loader/접근 가드를 변경하지 않았다.

모의고사 회차는 준비 확인 필요 상태였으므로 기존 disabled를 유지했다. 실제 신규 시험 시작·답안 제출·체크 저장은 하지 않았다.

## 운영

이 기록은 사전검수다. 정확 SHA CI/CD와 수정 후 실제 운영 메뉴/원문 확인은 별도 후속 단계다. 320/390 및 Safari/iPhone 실기기는 미검증이며 모든 페이지의 모든 상태를 완전검수했다고 주장하지 않는다.
