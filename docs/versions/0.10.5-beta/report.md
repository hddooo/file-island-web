# 0.10.5-beta 결과

## 현상과 수정
- 문화 표가 읽기 영역보다 넓게 고정되어 잘리고 가로 이동이 필요했다.
- 표를 화면 폭에 맞추고 좁은 화면은 구분·내용 쌍을 DOM·키보드 순서와 같은 순서로 세로로 이어 읽도록 수정했다. 원문을 줄이거나 글자 전체를 축소하는 방식은 쓰지 않았다.

## 현재 상태
- 구현·실제 원문 DOM 6뷰·합성 WebKit 20조건 검수 완료. 게시·배포는 이 기록 이후 정확 SHA로 별도 확인한다.
- 모바일 포커스 순서와 회사모드 좁은 label 여백을 검수 중 보완했다. 모든 셀 폭 내부, 13px 이상, 원문/ID/병합/헤더 불변.
- 기준 main에서도 실패하는 기존 JSDOM 글꼴/색상 계산 검사 2개는 미통과로 기록했다.
- 실제 원문 브라우저는 파일 전송 실패로 미실시. 실제 로그인·실기기 검수는 하지 않았다. 원문·정답·기록·권한·API는 변경하지 않았다.
- 이번 변경은 0.10.4-beta 위의 문화 표 수정만 포함한다. 기존 미배포 0.10.3은 포함하지 않는다.
