# 0.10.5-beta 진행

## 구현
- 문화 표의 최소 1160px 및 모바일 2배 이상 강제 폭을 제거했다.
- 넓은 화면은 13/37/13/37 비율의 네 열, 700px 이하는 구분·내용 두 열로 원래 DOM 순서(L1→R1→L2→R2)대로 세로 배치한다.
- 30개 원문 셀의 DOM·안정 ID·rowspan/colspan·헤더 연결과 17개 문화 갤러리는 유지한다.

## 검사
- 합성 셀 검사: 30개 셀, 기준 renderer와 내용/ID/병합/헤더 동일, 3회 재마운트 통과.
- 고려 세션·전송 계약, 고려 탭 77개, 시대 메뉴 저장 완료 40경우, 빈칸 안내 13개, 버전 빌더 검사 통과.
- 실제 비공개 번들: 6개 주제/모드, 기존 18개 인라인 설명·원문 불변 검사 통과.
- 실제 원문 DOM 6뷰를 기준 renderer와 비교: 문화 30셀·갤러리 17개·툴팁 29개 및 내용/ID/병합/헤더 동일. 모바일 grid와 native Tab DOM 순서 일치.
- 툴팁 hover/touch/Enter/Space/Escape/바깥 클릭/scroll/resize/교체/정리 상호작용 검사 통과.
- 기존 정치 표의 JSDOM 글자 크기 검사와 툴팁 색상 직렬화 검사(#d1d5db 대 rgb)는 기준 main에서도 동일 실패. 통과로 표시하지 않는다.
- 최종 제품 파일과 동일 SHA256으로 격리 Mac WebKit 합성 20조건 통과: 320/390/768/1024/1440 × 높이 900/420 × 기본/회사. 모든 30셀 폭 내부, 13px 이상, 30개 glossary native Tab/Escape와 모바일 시각 순서, 반복 주제/모드 및 unmount, 오류 0.
- 320/390/1440 기본·회사 캡처 직접 확인. 회사 문화 표의 장식 줄번호 공백 제거 후 320px label 가용폭 3.846em, 390px 5.154em으로 한 글자씩 꺾이던 문제 해소.
- 실제 원문 브라우저 검수는 정식 입력 전송 실패로 미실시. 실제 원문 DOM 검사와 합성 브라우저 검사는 다른 범위다. 클라우드 Chromium은 소켓 권한 오류로 실행되지 않았다.
- 초기 로컬 후보의 버전/정적 빌더 및 1,724파일 빌드 통과. 최종 커밋에서도 다시 실행한다.

## 게시·운영
- 미게시·미배포. 정확 SHA의 빌드·자동 배포와 실제 도메인은 별도 확인한다.
