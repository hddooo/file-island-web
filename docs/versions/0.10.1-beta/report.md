# 0.10.1-beta report

Goryeo and Joseon use the same four numbered learning actions as earlier eras, above the reading surface. Topic navigation remains available for reading modes and is hidden for the common era quiz. Repeated decorative reader titles were removed; source content and data contracts are preserved.

The page-leave guard skips only the two readers' internal mode buttons. Genuine departure still confirms unsaved work, cancellation retains the answer, and internal mode and browser history transitions preserve drafts. Retry / Save and the removal of review checkboxes from 0.10.0-beta remain intact.

This release changes presentation and its navigation integration, not API/database, source material, permissions or authentication. See progress.md for executed checks and legacy-test limitations. Exact CI/CD and live asset evidence are reported after publication. The all-era tooltip audit and unrelated English-island work are outside this release.
