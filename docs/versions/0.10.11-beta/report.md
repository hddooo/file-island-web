# 0.10.11-beta report

The requested early-Joseon policy/event tooltip additions are implemented without source-text changes. New entries explain Sohak promotion, Sogyeokseo abolition, Hyangyak promotion and the Sampo disturbance. Existing Hyeollyanggwa, merit cancellation, Yangjae poster and Eulmyo incursion definitions now include the requested details.

Historical cautions: Hyeollyanggwa used recommendation followed by a policy examination, not automatic appointment without an exam. Sogyeokseo was subsequently restored. Hyangyak nationwide promotion was attempted, not completed uniformly. The Eulmyo incursion helped Bibyeonsa become a permanent institution; it did not first establish the institution in 1555.

Public AKS / National Institute of Korean History source URLs are stored with each definition. Unrelated definitions, runtime code, private source, stable IDs and recall answers are preserved. Previously deferred parenthetical-removal requests remain excluded. Actual browser visual, physical-device and authenticated production-save tests remain unperformed. Build/deploy/domain results are recorded in the work log after execution.
