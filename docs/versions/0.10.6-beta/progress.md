# 0.10.6-beta 진행

## 구현
- 720px 읽기 영역보다 큰 일반 표 최소 760px·초기 왕 표 최소 900px를 없애고 열 너비를 백분율로 바꿨다. 기존 모바일 세로 배치와 시대 구분·문화 표의 비율은 유지한다.
- 회사모드의 장식 줄번호 여백이 구분·빈칸 너비를 차지하지 않도록 해당 표 안에서 제거했다. 백지 테스트 모듈과 채점 규칙은 수정하지 않는다.

## 검사
- 실제 비공개 원문 6뷰, 14표 177셀과 백지 입력 259개를 기준 renderer와 비교: 내용·ID·병합·헤더, 채점·정답 피드백·초기화·원문 복원 동일. 번들 불변.
- 문화 표 30셀, 고려 세션·탭77개, 백지 문맥 label8시대·구두점28·동의어217, 내부모드 세션, 메뉴40경우, 인라인설명18개/6뷰, 버전 빌더 통과.
- 기존 시대 구분 표의 JSDOM computed font-size 320/off 검사는 이전 기준에서도 실패하며 이번에도 동일하다. 전체 검사가 통과했다고 표시하지 않는다.
- 전체 백지 회귀 스크립트는 요구하는 개인 semantic 디렉터리와 고정 Windows 번들 경로가 없어 실행 불가. 원문 runtime 입력을 받는 이번 6뷰 회귀 검사로 고려 범위를 별도 검증한다. PNG 전송 회귀도 24개 그림 입력이 없어 이번에는 미실시.
- 동일 제품 해시의 격리 Mac WebKit 합성 20조건(320/390/768/1024/1440 × 900/420 × 기본/회사) 통과: 모든 2·3열표 및 시험 6표 가로 잘림 없음, 긴 답 자동 높이·320px 리사이즈·Tab/ShiftTab·맞음/틀림 피드백·반복 전환·오류 0. 4개 캡처 직접 확인.
- baseline은 table18 761px·table16 901px가 읽기 영역 666~718px를 넘는 현상을 재현했다.
- 독립 검수: 실제 원문 9뷰(개념·시험·실제 recall모드) DOM과 140개 실제 recall모드 입력·원문·헤더·병합·DOM 순서 불변, 새 차단 결함 없음.
- 실제 원문 브라우저는 정식 파일 전송 실패로 미실시하며 합성 브라우저와 실제 원문 DOM 범위를 구분한다.
