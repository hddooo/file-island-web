# 0.10.6-beta 결과

## 현상과 수정
- 앞선 문화 표 전용 0.10.5에 포함되지 않았던 무신 집권기 백지 테스트 표가 720px 읽기 영역보다 넓어 오른쪽이 잘렸다.
- 같은 폭 제약의 고려 일반 표·초기 왕 표를 화면 안 비율 열로 바꿨다. 원문을 줄이거나 글자를 전체 축소하지 않고 기존 모바일 세로 읽기와 백지 테스트 동작을 보존한다.

## 현재 상태
- 구현·실제 원문 DOM/백지 회귀·합성 WebKit 20조건 및 독립 검수 완료. 게시·배포는 이 기록 이후 정확 SHA로 별도 확인한다.
- 사용자 Chrome, 원문·정답·기록·권한·API 변경은 없다. 기존 미배포 0.10.3은 미포함.
- 실제 원문 브라우저·실제 로그인·실기기는 미검증이며 기준에서도 실패하는 JSDOM 시대 구분 표 글꼴 계산은 미통과다.
