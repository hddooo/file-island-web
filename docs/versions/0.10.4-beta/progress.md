# 0.10.4-beta 진행

## 구현
- 시대 메뉴의 개별 오답 다시보기 버튼을 비대화형 완료 표시로 교체했다.
- 저장 상태 조회·원문 버전 검증·삼국의 ancient ID 매핑·계정/화면 수명 보호는 유지했다.
- 실제 사용자 기록을 쓰거나 원문·개인 자료를 추가하지 않았다. 홍문관 전체 오답 복습은 유지했다.

## 검사 1 · 기능
- 8개 시대 × 5개 저장 상태, 40경우 통과: 빈/부분 미완료, 빈/부분 명시 완료, 기존 전체 응답 완료.
- 명시 완료 및 version guard, canonical ancient 연결 검사 통과.
- 오류 7종과 계정 전환·로그아웃·stop·화면 분리·재마운트 5종, 총 12경우 통과. 대기/오류/이전 계정 응답은 체크하지 않는다.

## 검사 2 · 회귀
- 저장/완료 61, 다시풀기 60, 오답 채점 17, 재풀이 세션 13, 메뉴/홍문관 통합 20 검사 통과.
- 클라우드의 별도 빈칸 navigation 브라우저 검사는 Edge 미설치로 시작 불가였다. 이 변경에서 해당 저장/이동 코드는 바꾸지 않았으며 이 검사 자체는 미실행으로 남긴다.

## 검사 3 · 반응형/시각
- 격리 Mac WebKit 메뉴 40경우 통과: 너비 320/390/768/1024/1440, 높이 900/420, 기본/회사 모드, mount 전후 모드 변경.
- 실제 앱 CSS에서 완료 3개만 체크, 개별 오답 버튼 0, 반복 전환·노드·클릭·hash 유지, 화면/행 overflow 0.
- 전체 오답 연습 6경우 통과: 320/390/1440, 기본/회사 모드. 8개 시대 로딩, 채점 전 답 숨김, 정오답, 16px 입력/44px 높이, inert·닫기·재열기 초기화 검증.
- 320/1440 기본·회사 및 390 회사 오답 창 캡처를 직접 확인했다. 성공 후 체크열을 24px로 줄여 320px 기본모드 텍스트 폭 64→88px, 설명 2~3줄 감소를 확인했다. 로딩/실패는 48px를 유지한다. Chrome·개인 로그인·실제 기기 검수는 하지 않았다.
