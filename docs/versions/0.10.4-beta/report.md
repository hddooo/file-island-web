# 0.10.4-beta 결과

시대 탐험 경로를 개별 오답 버튼 없이 완료 체크만 보이도록 변경했다. 저장된 답안·오답·완료 판정과 기존 학습 경로는 유지한다.

로컬 기능·회귀 9개 묶음, 격리 WebKit 46경우, 정적 빌드 및 빌더 2개 검사를 통과했다. 실제 로그인·실제 기기 및 별도 빈칸 navigation 브라우저 검사는 미실행이다. 원격 게시·운영 확인은 정확 SHA·도메인으로 별도 확인한다.

별도 미게시 0.10.3 변경은 포함하지 않았다. 다음 기능 통합 시 이 릴리스 위에 재통합하고 실제 RELEASE_VERSION을 다시 정한다.
