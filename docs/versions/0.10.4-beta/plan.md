# 0.10.4-beta 계획

## 범위
- 시대 탐험 경로의 8개 개별 오답 다시보기 버튼을 제거한다.
- 기존 저장 완료 규칙에 따른 완료 체크만 표시한다. 명시적 완료 및 기존 전체 응답 완료는 유지하며 미완료·로딩·오류는 체크하지 않는다.
- 원래 시대 버튼·ID·이동, 저장된 답안, 홍문관 전체 오답 복습을 보존한다.
- main `bd9563974c0ac9ed0beeaaff83ef55600da297c7`에서 독립 변경한다. 미게시 0.10.3 후보를 포함하지 않는다.
