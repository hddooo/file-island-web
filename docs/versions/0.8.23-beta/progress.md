- 원본 문제 PDF와 정답 PDF의 SHA-256이 기존 80회 import seed와 일치. 50문항 원문/공식 답지를 이미지로 확인하고 지문 해설 및 보기 설명 250개 작성.
- 3번② 및 13번②③의 불확실한 유물 고유명은 추정하지 않고 외형 구별로만 설명. 원고에 editorialLimit을 남겼다. 별도의 웹 역사 출처 교차 검증이나 공식 해설집 인증은 주장하지 않는다.

- 새 80회 자료는 기존 최종 채점 응답의 ID·버전·배점·정답·보기 전체 일치 시에만 display overlay로 적용. DB와 사용자 풀이 기록을 갱신하지 않는다.
