# 사전검수 결과

## 수정 범위

이전 회사모드는 시대 및 영어 하위 목록에 공통 색/글꼴만 덮어 실제 메뉴 구조가 남았다. 이번 수정은 시대, Vocabulary 최근 단어/추가/Chapter/체크 모음, Grammar 목차, Practice 파트, Listening 재생목록 및 Hall 순위를 실제 파일/행 구조로 보완한다.

라우트·원본 버튼·독립 PDF/연습 동작·disabled/ARIA·profile ref를 보존한다. 계정/학습 API, 답안, 체크 저장, XP/재생 컨트롤러는 변경하지 않는다. 최근 단어 팝업의 opener 노드도 그대로 사용한다. 일반모드에서는 회사모드 추가 표시만 제거한다.

Vocabulary 본문 간격은 양 모드에서 14px/12px 패딩과 8px 행 간격을 사용한다. 중첩 패딩을 줄이고 체크 열 52px 및 44px 컨트롤을 유지한다. 글자 크기/줄 높이/인쇄는 변경하지 않는다.

## 검사

- 새 메뉴 DOM/CSS 7개: 반복 전환, native 노드/handlers, 비활성 상태, async 교체/중복 방지, parked audio의 시간/노드 보존, 순위·프로필·페이지 상태, CSS 범위/구문.
- 단어 밀도 4개: 양 모드의 320/390/700/759/760/1024/1440 CSS 선언 cascade, 글자/44px 컨트롤 유지, 인쇄 선언 불변, 실제 단어 모듈의 합성 체크/필터/뜻/상세 동작. CSS 선언 검사는 실제 레이아웃 검사가 아니다.
- 기존 회사모드 중 독립 기능 회귀 18개 및 버전 빌더 통과. 전체 저장소 검사 성공을 의미하지 않는다.
- 이전 정확 SHA의 시대 목록 실제 Chrome 1180px에서 기존 70px 행 잔존을 확인했다. 수정 후 운영 화면은 배포 후 별도로 검수한다.

## 한계와 다음 단계

로컬 브라우저 실행/로컬 미리보기는 현재 환경에서 사용할 수 없다. 사전검수에는 실제 렌더링 엔진 검사가 포함되지 않는다. 정확 SHA CI/CD 후 실제 운영의 명시된 메뉴와 단어 본문을 검사한다. 320/390px 및 Safari/iPhone 실기기 검증은 별도로 남는다. 모든 페이지/상태를 완전 검수했다는 주장을 하지 않는다.
