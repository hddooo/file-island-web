기준 운영 main: 9bcc374e06c2abbcc067f9bdc8d996f6398ae0fb.

## 동작
실전모의고사 목록과 오답노트의 ‘오답 선택 · 인쇄 / PDF’에서 연다. 체크 선택은 회차 필터를 바꿔도 유지된다. 원본은 인증 API에서 blob으로만 가져오며 외부 렌더러나 저장소로 보내지 않는다. 문항의 원본 문제·보기를 두 단에 끊지 않고 배치한다. 같은 쪽의 공통 자료는 한 번만 두고 후속 문항에서 참조하며, 쪽이 바뀌면 다시 넣는다. 정답은 마지막 한 장에만 모으고 원래 선택답·해설은 렌더링하지 않는다.

## 검사와 한계
`scripts/test-cbt-wrong-print.cjs`는 선택/전체/다회차·계정 경계·늦은 응답·이미지 URL 정리·GET-only·정답/해설 분리·500항목 보존·두 단 배치를 검사한다. JSDOM은 실제 페이지 높이·iOS PDF를 보장하지 않는다.

`NODE_PATH=… node scripts/qa-cbt-wrong-print-fixture.cjs OUTPUT`는 개인정보 없는21/500문항 HTML을 만든다. 21문항 fixture는8문제쪽+1정답쪽이다. Mac Chrome에서 열고 로드 후 document.title의 overflow가 빈 배열인지 확인하고 A4 세로/100%/머리글·바닥글 끄기로 인쇄 미리보기를 확인한다. 500문항 fixture도 정답쪽은 정확히1장이어야 한다.

PDF 직접 바이너리 다운로드가 아니라 브라우저/OS 인쇄 및 PDF 저장이다. 한국어는 원본 이미지와 OS 글꼴로 처리하고 커스텀 미포함 PDF 글꼴은 생성하지 않는다. iOS Safari 인쇄 화면에서 공유/파일 저장이 필요하며 저장 완료는 웹에서 확인할 수 없다. 이전 단일 회차 PDF 다운로드는 유지했다.

기존 notebook API는 최대500문항/hasMore를 제공하며 pagination이 없다. hasMore 또는 부정확한 항목이 있으면 전체 인쇄를 차단한다.500개를 넘는 전체 인쇄는 API 확장이 필요하다. 큰 문항은 한 단에 온전히 맞추므로 원본 비율이 아주 길면 작아질 수 있다. 긴 문항·공통자료의 실제 가독성은 실기기 검수해야 한다. 많은 이미지의 출력은 기기 메모리/인쇄 처리 한계가 있으며 실패 시 선택을 나눠야 한다.

소스 이미지가 누락되거나 목록이 준비 중 변경되면 PDF/인쇄 준비를 취소한다. 정답 마지막 장이 실제 렌더링 높이를 넘으면 선택을 줄이라는 안내로 차단하며 조용히 누락하지 않는다.
