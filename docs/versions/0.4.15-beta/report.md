# 0.4.15-beta · 단어장 예문 수정

기준 main: `7eb1c0f83d11ccd566179a71af11af94e6349888`.

## 변경

기존 관리 권한이 확인된 계정에만 일반 단어의 Tip 안에 예문 수정 버튼을 표시한다. 영어 예문·한국어 해석만 편집하며, 단어 ID·뜻·품사·동의어·출처·다른 단어와 학습 기록은 바꾸지 않는다. 별도 표시 규칙이 있는 paired-adverb, press conference, 변환된 학습 예문과 보충 자료는 제외한다. API·인증·권한 계약은 변경하지 않는다.

## 검수

- `scripts/test-note-example-edit.cjs`: 합성 DOM/모의 API의 12개 시나리오 그룹 통과. 관리 권한·원본 유형·revision 재확인, 중복 submit, 응답 유실 후 조회, 계정 전환/로그아웃, 취소·초안 복귀·원문 보존·텍스트 안전 렌더링을 포함한다.
- 기존 단어 추가 검사의 12개 시나리오 그룹과 변경 전후 읽기 화면의 16개 DOM 비교 통과. 소유자 예문 편집 버튼을 제외한 기존 보기·체크·필터·Chapter 동작은 동일하다.
- 독립 코드 검토 후 특수 표시 항목 제외 가드를 보완하고 전체 관련 검사를 다시 통과했다.
- Node 24 JS 구문 통과. 새 CSS는 없으며 기존 입력/버튼 스타일을 재사용한다.
- 사전 Chromium 시각 검사는 실행 환경의 socket 권한 문제로 시작하지 못했다. 모바일·실기기 검수 완료로 표시하지 않는다.

이 기록은 게시 전 검수 근거다. 정확 커밋의 정적 빌드·자동 배포와 실제 인증된 운영 화면의 저장·재조회는 게시 뒤 별도 확인한다.
