# 결과와 한계

공통 79회에는 적용하지 않고 기존 81회 capability에서만 표시를 변경한다. 전체/체크 보기 버튼 하나가 현재 모드·목표 동작·체크 수를 aria-label/aria-pressed로 전달한다. F2/Escape는 입력 ARIA 설명과 함께 유지한다. 마지막 Tab/첫 Shift+Tab은 기본 브라우저 경계를 유지한다.

성공 문구의 hidden 표시만 바꾸며 pending/error/retry와 저장 응답은 유지한다. pointerdown부터 click 완료까지 상태 문구의 높이 변경을 늦춰 체크와 버튼 클릭이 빗나가지 않게 한다. 종료 시 해당 타이머·리스너도 정리한다.

검증 범위: 표적7개 기능·CAS·복구·계정/세션 검사, 실제 index 320/390/1440px 고려·조선의 실제 Tab/Shift+Tab/F2/Escape, 반복 toggle/빈목록/입력과 체크 복원, 터치와 마우스 blur 채점, 숨긴 성공 영역 높이0 및 실패 표시. 기존 용어 설명 소스는 그대로이며 44표현 검사를 다시 실행한다.

별도 lint/typecheck 명령 없음. node --check/diff 검사와 정적 build를 적용한다. 기존 progress-recovery JSDOM null _location, period 고정 byte/hash 제약 및 전체 private corpus 기본경로 부재 검사는 미재실행/미실행 한계를 유지한다. 실회원·물리 iPhone/VoiceOver 미검증. 합성 회원 화면을 운영 실회원 검사로 표현하지 않는다. 개화기·원문·진도·API·권한은 변경하지 않는다.
