# 구현 및 검수

- 개념 학습의 기존 인증 경로와 판본 검증을 재사용한다. 실제 원문 데이터 및 정답은 프런트 정적 파일에 복제하지 않으며 계정·세션 변경 시 렌더링 결과를 정리한다.
- PDF 버튼은 실제 표 로딩이 완료된 뒤 현재 페이지의 브라우저 인쇄를 연다. 표의 행과 내용은 축약하지 않는다.
- 테스트: 합성 원문 표의 순서/값 보존, 시험/정답 영역 제외, 계정 격리, 로딩 재시도, 기존 점검 및 인쇄 호출은 `scripts/test-history-weakness.cjs`.

세 차례 검토에서 반영한 사항:

1. 원문 보전: 행·열·병합·하위 표를 그대로 가져오고, 무덤·지역 등 주요 원문 그림과 개화기 원문 연표도 유지한다. 개념 학습만 사용하며 시험/정답 영역은 읽기 페이지에 표시하지 않는다. 판본·쪽수와 원본 바로가기, 그림 미표시 경고를 둔다.
2. 기출 범위: 74회 38·48·50번, 75회 3·35·38번의 연결 단서를 원문과 별도 표시했다. 대한민국·일제강점기 관련 단원의 원문 개념 표는 키워드 제한 없이 유지한다.
3. 역사 검증: 400년 시기, 433→475→493년 배열, 금관가야의 항복·편입, 551→553→554년 한강 관계, 법흥왕의 병부·상대등, 천리장성의 방어 목적을 확인했다. 근거: 국사편찬위원회 한국사데이터베이스 삼국사기 `sg_004r_0030_0150`, `sg_026r_0060_0190`, HanQ 시대별 학습/실전모의고사.
