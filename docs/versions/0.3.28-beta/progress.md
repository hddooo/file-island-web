# 0.3.28-beta · 진행

기준 main: `2d05bec69767292dfb1587330a1980c1b97eb319`.

## 구현·소스 검증

- 모달 제목·내용·전송, 기존 URL 연결, MY PAGE 본인 문의·관리자 답변 표시를 구현했다. 기존 ADMIN은 유지한다.
- API client에는 선택적 `feedback:false`만 전달하는 인자를 추가했다. 문의 모달의 자체 진행·결과 안내와 공통 대기창이 겹치지 않게 하며, 기존 호출은 같은 기본 동작을 유지한다.
- 후기 코드 검토에서 BFCache 복귀의 목록/전송번호 유실을 찾아 수정했다. 캐시 복귀는 세션을 다시 확인한 뒤 연결된 목록만 복원하고, 같은 로그인에서 미확인 전송 번호를 보존한다.
- 문의 UI 63개, 실제 API client와 공통 요청 안내를 사용하는 합성 HTTP 검사 23개, 계정/API 45개, MY PAGE 7개가 통과했다. 버전 빌드·반복 빌드·입력 제한·배포 헤더 검사도 통과했다.
- 운영의 기존 문의 페이지에서 검색·제목·내용과 로그인된 빈 목록을 읽기로 확인했다. 운영 문의 생성·답변·계정 변경은 하지 않았다.

## 한계·배포 확인

이 실행기의 Chromium은 socket 권한 제한으로 실행되지 않는다. 우회하지 않았으며 로컬 렌더링, 실제 BFCache, 모바일/Safari 검수는 통과로 표시하지 않는다. 새 브라우저 검사는 기존 독립 문의 장면 검사 진입점과 연결하며 합성 fixture임을 구분한다.

이 커밋의 정확 SHA 빌드·자동 배포와 운영 버전/HTML·모달 동작 확인은 게시 이후 별도 수행한다. 합성 소스 검사 성공을 운영 배포 완료로 간주하지 않는다.
