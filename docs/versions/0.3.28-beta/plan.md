# 0.3.28-beta · 간단한 건의·문의

목표: 별도 복잡한 문의 화면 대신 제목·내용을 쓰고 보내는 창을 제공한다. 사용자는 MY PAGE에서 자신이 보낸 문의와 답변을 확인하고, 관리자는 기존 ADMIN에서 확인·답변한다.

- 지도 문의 링크와 기존 `/inquiries/` URL을 같은 모달로 연결한다.
- MY PAGE에 기존 서버의 본인 문의 목록과 메시지를 연결한다.
- 중복 전송, 결과 미확인 재시도, 계정/화면 수명, 캐시 복귀와 잠금 해제를 검증한다.
- API/DB 데이터·인증·권한·관리자 답변 계약은 변경하지 않는다.
- 기능/회귀 검사, 정확 SHA 빌드·배포, 실제 운영 화면을 구분해 확인한다.
