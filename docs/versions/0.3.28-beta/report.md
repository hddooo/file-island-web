# 0.3.28-beta · 결과와 검증 경계

사용자 흐름은 지도 건의·문의 → 제목/내용/보내기 → 서버 접수 확인이며, 보낸 문의와 관리자 답변은 MY PAGE의 내 문의에서 확인한다. 기존 `/inquiries/` 주소는 유지하고 같은 흐름으로 연결한다. ADMIN 문의함·답변 작성과 기존 문의·추가 메시지·감사 데이터는 보존한다.

새 코드는 실제 기존 API만 호출한다. 합성 응답은 scripts의 검사에만 존재한다. 사용자별 데이터는 서버의 인증·소유자 검사와 화면의 계정/로그인 세대 검사를 함께 따른다. 전송 중 중복 클릭을 막으며 불명확한 결과는 동일 전송번호와 내용으로만 다시 확인한다. 성공은 서버가 문의 ID를 반환한 뒤에만 표시한다.

단위/회귀 결과와 브라우저 실행 한계는 [진행 기록](progress.md)에 있다. 현재 결과는 구현·소스 검증 완료이며, 정확 SHA CI/CD·운영 화면 확인을 별도 증거로 대조해야 한다. 이 문서만으로 운영 배포나 실제 모바일 검증을 주장하지 않는다.

다음 검증: 실제 배포의 app-version/HTML build 일치, 기존 URL의 모달 진입, 제목·내용만 존재하는 창, 닫기/Escape 후 복귀, MY PAGE 본인 목록, ADMIN 경로 유지. 실제 문의 제출을 검수 데이터로 생성하지 않는다.
