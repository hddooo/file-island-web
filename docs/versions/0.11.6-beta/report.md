# 검증 범위

실제 81판 8개 시대 697문항의 정답을 점검하고, 기존에 거부되던 7종의 정확한 canonical 별칭만 추가. 원본 정답·문항 ID·기존 기록·v1·DB·보안은 유지. 민립대학 설립/건립, 천진/톈진, 실제 버전에 결합된 촌락문서/민정문서는 기존 지원이라 변경 제외.
실제 자료 입력 검사와 메모리 DB 어댑터 서비스 검증이며 운영 사용자 제출/기록 수정 없음. 전체 API suite는 private fixture를 갖춘 pinned base CI에서 최종 확인.
