### 배포 가능한 FE와 서버 의존 기능

이번 FE 묶음에서 기존 API와 함께 사용할 수 있는 부분은 세계 아트/입장·FX·중앙 수락/거절·발신 대기/취소 모달이다. 기존 서버가 반환하는 30초 만료를 그대로 표시한다. 새 API 배포 전에는 10초 초대, 여러 초대 대기열, 탭별 lease, 정확한 전투 상대 표시, 한국사 봇, 수동 진화가 운영에서 완료됐다고 표시하면 안 된다. 이들은 partnerEvolution 응답을 확인한 경우에만 활성화된다.

새 API는 sessionId를 요구하므로 향후 배포는 호환 FE를 먼저 준비한 다음 API/마이그레이션의 실제 적용을 확인해야 한다. 오래 열린 이전 FE 탭의 재로딩/호환 전략도 확인해야 한다. 현재 API runner offline 문제는 이 검수에서 해결하거나 우회하지 않았다. 원격 push·배포는 부모 최종 신호 대기 상태이며, 이 로컬 통과 기록은 운영 반영의 근거가 아니다.
