# 독도와 간도 웹툰 · 근거와 구성 기록

웹툰 `media/islands-comic.html`과 장면 지도 `docs/islands-comic-map.json`은 `scripts/build_islands_comic.py`가 만든다(여러 번 실행해도 결과가 같다). `scripts/build_comics.py`는 이 시대를 건너뛴다.
주제 머리와 ‘이 부분에서 외울 것’ 카드는 `media/lecture-flow-islands.js`의 두 주제 데이터(`/*FLOW-JSON*/` … `/*END-FLOW-JSON*/`)를 그대로 읽는다. 앱(`index.html`)도 같은 데이터로 학습 화면의 두 주제 바로 가기와 안내를 그린다.

## 내용의 근거

- 새 사실·연도·정치적 주장은 더하지 않았다. 모든 글은 아래 두 곳에 이미 있던 내용만 옮기거나 문장으로 풀었다.
  - `index.html`의 독도와 간도 노트 카드 5장(지증왕·이사부·우산국 / 숙종·백두산정계비 / 러일전쟁 중 독도 불법 편입·한일의정서 → 제1차 한일협약·을사늑약 / 서간도·북간도 독립운동 기지 / 봉오동 → 청산리 → 간도 참변 → 자유시 참변 → 미쓰야 협정).
  - 기존 웹툰 7컷의 제목·대사·꼭 기억 단서.
- 백두산정계비의 1712는 강의 스크립트에 없는 연도다(아래 표의 965–967행에는 연도가 없다). 앱에 이미 있던 조선 자료에서 가져왔다: `media/lecture-flow-joseon.js`의 ④ 흐름 ‘예송과 환국’ 덩어리(L02 · 19대 숙종, “백두산 정계비를 세웠다(1712)”). `docs/joseon-scene-sources.md` 3절은 1712를 ‘표준 조선 연표를 따랐고 공식 출처와 하나하나 대조하지 않은’ 연도로 적고, L02의 교재 대조 쪽은 PDF 65, 67, 72쪽(강의 분석의 모듈별 대조 쪽)이다. 교재의 해당 쪽은 이번에 다시 열지 않았다. 감독 QA에서 2026-10-07 국사편찬위원회 우리역사넷의 [백두산 정계비 사료·해설](https://contents.history.go.kr/mobile/hm/view.do?levelId=hm_099_0090)을 별도로 읽어 1712년(숙종 38) 건립을 확인했다. 강의 원문에 연도가 있다는 뜻은 아니다.
- 나머지 장면에는 연도를 새로 붙이지 않고 ‘신라 지증왕 때’, ‘러일전쟁 무렵’, ‘정계비보다 훨씬 뒤’처럼 원래 단서의 시기 표현만 쓴다.
- 북간도 학교는 “이상설이 세운 서전서숙이 있었고, 명동학교도 있었다”로 나눠 쓴다. 이상설이 세웠다는 것은 서전서숙뿐이다(아래 1806–1807행). 명동학교는 노트 카드에만 있고, 세운 사람은 적지 않는다.
- 노트 카드·빈칸·기출 문항은 바꾸지 않았다.

## 강의 스크립트 대조

- 대상: 강의 스크립트 `hanq_scirpt.md`(조선 근거 문서 1절의 같은 이름 파일. 이번에 해시는 다시 계산하지 않았다)의 독도·간도 관련 행만 봤다: 243–246, 962–970, 1482–1492, 1753–1778, 1806–1812.
- 스크립트는 음성 인식 받아쓰기라 이름이 깨져 있다. 아래 ‘바로잡은 이름’은 앱 노트 카드와 기존 장면에 이미 있는 이름으로만 고쳤다. 앱에 없는 이름·번호는 고쳐 넣지 않고 쓰지도 않는다.
- 스크립트는 사실과 순서를 대조하는 데만 썼다. 강조 등급이나 출제 빈도는 이 시대에 매기지 않는다. 이 범위 밖 내용(순장 금지, 토문강 해석, 고문 정치, 화폐 정리 사업, 권업회 등)은 웹툰에 넣지 않았다.

## 두 주제로 나눈 까닭

예전 웹툰은 우산국 → 백두산정계비 → 러일전쟁 → 간도 순으로 이어져 한 땅의 이야기가 시간 순서대로 이어지는 것처럼 읽혔다. 실제로는 서로 다른 두 주제이고, 주제 안에서도 옛일과 뒷일 사이가 크게 떨어져 있다.

- ① 독도: 신라 지증왕 때 이사부의 우산국 복속 … (시대가 크게 떨어짐) … 러일전쟁 중 일본의 독도 불법 편입. 같은 무렵의 한일의정서 → 제1차 한일협약 → 을사늑약은 같은 전쟁 시기의 침탈로 묶을 뿐, 독도 편입이 조약을 일으켰다고 잇지 않는다.
- ② 간도: 조선 숙종 때 백두산정계비(청과의 국경) … (훨씬 뒤) … 서간도·북간도 독립운동 기지 → 독립군 전투와 시련.
- 두 주제 사이에는 ‘주제를 바꿔, 시대를 거슬러 간다’고 밝힌 줄을 두고, 앞 주제의 결과로 잇지 않는다.
- 주제 안의 큰 시대 건너뜀은 장면 사이 줄에 ‘시대가 크게 건너뛰어요’로 밝힌다.
- 두 주제를 하나의 시간 순서처럼 잇던 예전 연결 문장 셋은 뺐다. 나머지 연결 문장은 그대로 둔다.

## 대화

- 말풍선은 그림 밖(아래)에 두고 ‘학습용 요약 대화 · 실제 발언을 그대로 옮긴 것이 아님’을 표시한다.
- 이사부 말고는 기록에 이름이 없는 화자라 ‘설명용 인물’로 밝힌다. 예전 ‘조선인’은 러일전쟁 무렵(대한제국)에 맞게 ‘대한제국 사람’으로 고쳤다.
- 정계비 컷에서 뒷날(독립운동 기지)을 미리 말하던 ‘뒷날의 독립운동가’는 시간 여행 대화처럼 읽히지 않도록 ‘해설 · 뒷날을 미리 짚음’으로 바꿨다. 대사는 그대로다.
