# Part1 source-image crop candidates (not deployed)

Copy media/part1-extract.js and optional media/part1-crop-review.js into frontend static assets. No third-party dependency, upload, network API, image generation or original mutation.

1. await HanqPart1Extract.propose(file,{lines:ocr.lines,highlights:ocr.highlights,signal}). PNG/JPEG/WebP up to8MiB and20MP; side<=10000. Result originalSha256/sourceWidth/sourceHeight/candidates[{bbox,score,reasons,needsConfirmation:true}]. score is heuristic ranking, not calibrated probability. OCR/mask coordinates must refer to the same EXIF-oriented decoded source.
2. Display original and candidate rectangle. User must choose/adjust and confirm. If no candidate, show manual selection; do not claim automatic success. Optional HanqPart1CropReview.mount(host,file,result,{isCurrent,onConfirm,onCancel}) provides numeric coordinate editing and explicit click confirmation. Return .stop() revokes local object URL and aborts in-flight crop; call on navigation/account switch/reset.
3. confirmCrop(file,bbox,{userConfirmed:true,originalSha256,signal}) validates integer bounds, min32x32, original file hash; returns {blob,provenance}. Provenance contains original hash, decoded-image-exif-applied coordinate space, source size, crop rectangle, output dimensions/hash, userConfirmed, generatedContent:false. PNG output is exact selected decoded pixels, not regenerated content. The original file and bytes are unchanged. No source EXIF copied into cropped PNG.
4. Parent workflow can attach confirmed PNG as clean_image only after explicit user action; this helper does NOT upload or grant image approval. Preserve original source_image asset. Retain provenance in request metadata/note if backend contract supports it; never imply backend saved fields it rejected. Server image review remains required.

Detection downsamples only for locating large connected non-white/texture regions, masks OCR text and bright marker candidates, returns up to3 regions. It does not erase markers/text or reconstruct obscured image. White-background photos, perspective, multiple columns, drawings and overlapping text may fail or yield incomplete bounds. Manual original comparison is mandatory. No real textbook photo provided, so actual-source accuracy is unverified.

Test: test-browser.cjs uses a synthetic local page with masked title/choices and a grayscale image rectangle; detector found the picture region, confirmed crop pixels equal source pixels byte-for-byte, invalid bounds/missing confirmation/changed-source hash reject, explicit UI confirmation required,375px screenshot inspected with no overflow, network only localhost and local blob preview. Real mobile Safari not tested.
